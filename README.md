# Student Productivity Dashboard

## Overview
The Student Productivity Dashboard is a web-based productivity management application designed to help students organize tasks, track goals, and improve focus using Pomodoro sessions. The application also provides productivity analytics and progress tracking through an interactive dashboard.

## Features
- Task management system
- Goal tracking functionality
- Pomodoro focus timer
- Weekly productivity analytics
- Dark/Light mode toggle
- Motivational quotes and productivity tips
- Local Storage-based data persistence
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage API

## Functionalities
### Task Management
- Add, complete, and delete tasks
- Maintain completed task history

### Focus Tracking
- Pomodoro timer for study sessions
- Weekly focus-time analytics

### User Experience
- Responsive dashboard design
- Dark and light theme switching
- Persistent data storage without backend

## Future Improvements
- User authentication system
- Cloud database integration
- AI-powered productivity recommendations
- Mobile application version
